# Blood Donation Management System

## 📌 About the Project

The Blood Donation Management System is a web-based application designed to manage blood donors, blood inventory, and blood requests efficiently. It helps hospitals and blood banks maintain blood availability and manage donor information.

## ✨ Features

- User Registration and Login
- Donor Management
- Blood Inventory Management
- Blood Request Management
- JWT Authentication
- Blood Group Tracking
- Hospital Blood Requests
- Real-time Inventory Updates

## 🛠️ Technologies Used

- Node.js
- Express.js
- MongoDB
- MongoDB Atlas
- JWT
- React.js
- JavaScript
- HTML
- CSS

## 🎯 Objective

The main objective of this project is to provide an efficient system for managing blood donors, blood stock, and blood requests in a centralized platform.
